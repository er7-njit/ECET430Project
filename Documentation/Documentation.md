## Device Summary
The Pi Tracker is a tracking device that utilizes an Adafruit GPS module and a Sierra EM7455 WWAN Module to wirelessly transmit its location to the cloud. Its base componentry is a Pi Zero W (Figure 1), Adafruit Ultimate GPS (Figure 2), and Sierra EM7455 WWAN Interface (FIgure 3) attached via a miniPCIe to USB adapter.
